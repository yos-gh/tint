# TINT (TINT is not Tetris)

物理演算を使った、テトリスによく似た落ち物パズルを作ってみましょう。基本的なルールは一般的なテトリスのそれに準じるので適宜補完してください。

## Tetrisとの違い

### ブロックについて

- ブロック基本的な形状（T字、L字、真っ直ぐ、など）はテトリスと同様です
- ブロックを構成する石は四角ではなく角丸です
- 石同士は固定されているのではなく、ゴムのように伸縮する糸で連結されています
- 落下の衝撃や、周囲のブロックの重量、圧力によって紐が伸縮し、ブロックの形状が歪みます
- ブロックの形状は、歪んでも元の形状からかけ離れない程度にしてください
- 石自体も弾性をもち、衝撃で一定程度弾みます
- 落下時の回転は90度単位ではなく、ボタンを押した時間だけ回り（1秒で1回転程度）、任意の角度で落とすことができます

### 行・列と消去について

- 明確な行と列はありません
- 左の壁に接している石と、同じ高さで右の壁に接している石の組み合わせを「ペア」とします
- 「ペア」となる石同士をつないだ直線の上に一定数（線分上に単純に石を直列した数より1を引いた数）以上の石が存在する場合、その直線上にある石が消去されます
- 石が消去されるとき、それに結びついた紐も同時に消えます

### フィールドについて

- ブロックが配置されるプレイフィールドの底辺は水平ではなく、中央が窪んだ円弧にし、ブロックを素直に積めないようにします

### 操作方法

- 左右移動 : A, Dキー、左右矢印キー
- 落下加速 : Sキー、下矢印キー
- Spaceで回転、Nキーで逆回転
